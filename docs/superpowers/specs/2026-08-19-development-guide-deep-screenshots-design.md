# 開發文件深層畫面補充設計

## 目的

讓工程師從開發文件直接看懂「年度專案 → 範圍／區域 → 零散點位」的資料層級與操作動線，同時移除不需要交付給工程師閱讀的「截圖來源與限制」。

## 修改範圍

- 移除 `spec/地礦AI_功能模組與開發分工說明.md` 的第 9 節全文。
- 只補充 5.3 建議監測點位、5.4 監測區位選定、5.6 判釋變異點結果及查勘回報的深層畫面。
- 不改動 RBAC、工程師分工、按鈕說明與業務規則。

## 畫面層級

### 5.3 建議監測點位

1. 年度監測專案列表。
2. 判釋範圍／區域列表。
3. 選定範圍內的建議監測點位列表。

### 5.4 監測區位選定

1. 年度監測專案列表。
2. 建議監測範圍列表。
3. 選定範圍內的監測點位列表及地礦中心操作按鈕。

### 5.6 判釋變異點結果及查勘回報

1. 年度監測專案列表。
2. 判釋變異範圍列表。
3. 選定範圍內的變異點列表。
4. 地方政府通報／查勘表單維持原圖，作為點位後續處理畫面。

## 呈現方式

- 使用一般 Markdown 圖片與一句簡短圖說，不增加卡片、表格或裝飾排版。
- 主要流程畫面使用地礦中心承辦角色；地方政府查勘表單保留地方政府角色。
- 截圖必須顯示足以辨識層級的頁面標題、年度／範圍代碼與列表內容。

## 驗證

- 每個新增圖片連結都能在 GitHub Markdown 正常解析。
- 三個模組的圖片順序與雛形層級一致。
- 第 9 節及其三個限制條目完全移除。
- 不納入系統管理員業務畫面。
