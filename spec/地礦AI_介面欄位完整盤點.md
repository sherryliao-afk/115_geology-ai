# 地礦 AI 介面欄位完整盤點

版本：草案 v1
盤點依據：目前 `index.html` 雛型之可見畫面與角色操作
適用角色：地礦中心承辦、空拍廠商、地方政府人員、系統管理員

## 1. 文件定位

本文件只盤點雛型畫面已出現的查詢條件、清單欄位、表單欄位、附件及狀態，不代表後端已實作，也不把雛型假資料視為正式需求。

欄位標記：

- **輸入**：使用者可輸入或選擇。
- **顯示**：畫面帶入或唯讀呈現。
- **系統**：由系統計算或自動產生。
- **附件**：上傳或下載檔案。
- **待確認**：畫面存在，但定義或規則尚未確認。

## 2. 全系統核心認知

「建議監測點位」、「監測區位選定」及「判釋變異點」是一條龍流程中的同一批點位資料。點位通過每個模組時只更新階段註記；未通過的點位仍保留，不應刪除或複製成另一筆點位。

```text
AI 判釋點位匯入
  → 建議監測篩選
  → 監測區位選定
  → 拍攝與成果上傳
  → 變異判釋
  → 地方政府查勘
  → 稽催／違規續處／結案
```

雛型中的 `MG`、`SP` 範圍代號為假資料，不賦予正式業務意義。
